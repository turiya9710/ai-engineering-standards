# Engineering Principles

## General
- Prefer simple, maintainable solutions.
- Understand existing architecture before changing code.
- Avoid unnecessary dependencies.
- Favor explicit interfaces and clear responsibilities.
- Preserve backwards compatibility unless explicitly changing it.

## Engineering discipline
- Define acceptance criteria before implementation.
- Prefer small, reviewable changes.
- Write tests for meaningful behavior.
- Never claim tests passed without executing them.
- Document significant architectural decisions.

## AI agent behavior
- Inspect the repository before proposing changes.
- Ask questions when requirements are ambiguous.
- Do not invent APIs, dependencies, or infrastructure.
- Explain tradeoffs before major architectural decisions.
- Do not modify unrelated files.
- Never expose credentials, tokens, or secrets.1G
